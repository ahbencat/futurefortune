# 将来会有钱的 - 中国彩票历史数据整理及可视化平台

## 简介

将来会有钱的 是一个专注于中国体育彩票历史数据整理与可视化的开源平台。目前包含**排列三**、**排列五**和**超级大乐透**三种彩种的完整历史开奖数据，后续将逐步增加更多彩种。

## 数据来源

- **数据范围：** 2004-11-14 至 2026-10-09
- **数据总量：** 排列三 7,743 期 / 排列五 7,735 期 / 超级大乐透 2,932 期
- **更新频率：** 每日自动更新

## 核心功能

- **历史数据表格：** 分页展示全部历史开奖记录
- **搜索筛选：** 支持按期号搜索、按年份筛选
- **号码频率统计：** 统计各位号码（0-9）出现次数
- **走势图：** 和值分布、跨度分布可视化
- **冷热号分析：** 基于最近 30 期的号码活跃度分析
- **遗漏值：** 显示每个号码距离上次开出的期数

## 技术特点

- **纯静态站点：** 无需后端服务器，部署简单
- **自动更新：** GitHub Actions 每日定时爬取最新数据
- **响应式设计：** 支持桌面端和移动端访问
- **开源免费：** 代码完全开源，可自由部署
